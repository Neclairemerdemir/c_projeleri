# ⚡ C Programlama ve Algoritma Çalışmaları

Bu depo, Bilgisayar Mühendisliği eğitimim süresince C dili ile geliştirdiğim temel algoritmaları ve oyun mantığı çalışmalarımı içermektedir.

## 🚀 İçerikte Neler Var?

* **adamasmacaoyunu.c:** Kullanıcın kelimeyi tahmin etmeye çalıştığı, döngüler ve dizi (array) mantığı kullanılarak geliştirilmiş klasik Adam Asmaca oyunu.
* **taskagitmakas.c:** Rastgele sayı üretimi (`rand()`) ve koşullu ifadeler kullanılarak hazırlanan Taş-Kağıt-Makas uygulaması.

## 🛠 Teknik Araçlar
* **Dil:** C
* **Derleyici:** Dev C++
* **Kazanımlar:** Temel girdi/çıktı işlemleri, döngüler, diziler ve rastgelelik yönetimi.

## 📌 Gelişim Notu
C dili ile yazdığım bu projeler, bilgisayarın çalışma mantığını ve bellek yönetimini anlamamda temel oluşturuyor. Hedefim, bu düşük seviyeli programlama yetkinliğini ileride **Siber Güvenlik** alanındaki teknik analizlerimde kullanmak.
